# Синхронизация через свой сервер

Сделана по образцу «Монетки». Код клиента — раздел «синхронизация через свой сервер» в `app.js`,
сервер — `server/` (подробности установки — `server/README.md`).

## Статус
**Работает** (с 31.10.2026): приложение — **https://kartochki.lav11.com**, сервер синхронизации —
**https://kartochki-sync.lav11.com** (Caddy → служба `kartochki-sync`).
DNS в Cloudflare (режим «DNS only»): `kartochki-sync` — A-запись на сервер, `kartochki` — CNAME на GitHub Pages.

## Как устроено
- Данные по-прежнему хранятся на устройстве (`localStorage`): приложение работает без интернета.
  На сервер уходит **зашифрованная** копия; сервер видит только `rid`, время изменения и шифр.
- **Единица синхронизации — набор целиком** (с карточками и прогрессом) **или папка**
  (`qv.folders`: `{ id, title, setIds, created, syncAt }`). У каждого есть `syncAt`.
  `saveSets()` сравнивает наборы и папки с прошлым снимком (`setHashes`, ключи `set:<id>` / `folder:<id>`),
  сам ставит `syncAt` изменённым, а исчезнувшие заносит в `qv.deleted` (`[{ k: 'set'|'folder', id, at }]`;
  старые записи без `k` — это наборы).
- **Ключ синхронизации** — 32 символа Crockford base32 (19 случайных байт + байт проверки от опечаток).
  Из него через HKDF-SHA256 (соль `kartochki-sync-v1`) выводятся ключ AES-GCM-256, ключ HMAC для `rid`,
  токен входа и номер «пространства». Сервер хранит только SHA-256 токена.
- **Запись:** `rid` = HMAC(`set\n<id>` или `folder\n<id>`), `ts` = `syncAt` (или время удаления), `blob` = `iv.шифр`
  (в AAD — `rid:ts`). Внутри `{ s: набор }`, `{ f: папка }` или `{ d: { k, id, at } }`. Побеждает более поздний `ts`.
- **Когда:** через 4 с после сохранения, при открытии и возвращении в приложение, при появлении сети, раз в 5 минут.
  Во время упражнения экран не перерисовывается; ответы пишутся в карточку, найденную по id (`findCard`).
- **Учёба по папке:** `folderDeck(f)` собирает все карточки наборов папки в один «набор» (`isFolder: true`);
  прогресс пишется в сами карточки, рекорд подбора пар — в папку.
- **Подключение устройства:** сначала всё скачивается. Если на устройстве только демо-набор — его наборы
  заменяются серверными; иначе спрашиваем: заменить или объединить.
- Настройки синхронизации — `localStorage['qv.sync']` (`server`, `key`, `cursor`, `pushedAt`, `lastOk`).
  **Ключ Gemini и модель** тоже синхронизируются: запись `rid('ai','')`, внутри `{ g: { apiKey, model, models, at } }`,
  время правки — `settings.aiAt` (ставит `saveAI()`); побеждает более поздняя правка, удаление ключа тоже передаётся.

## Сервер
- Каталог `/srv/kartochki-sync`, служба `kartochki-sync` (порт 8788 только на 127.0.0.1),
  ежедневная копия базы (`kartochki-sync-backup.timer`, 14 дней).
- В `.env` — `KARTOCHKI_ORIGINS` (адреса приложения, с которых разрешены запросы).
- Наружу — только через Caddy по https. Адрес сервера в репозиторий не записываем.
