# Карточки

Приложение для изучения слов по карточкам — как Quizlet, только с умной проверкой ответов и ИИ-заданиями.

## Возможности
- **Режимы:** карточки, письмо, тест, подбор пар, ИИ-задания.
- **Умная проверка:** регистр, пунктуация и «ё/е» не важны; варианты через « / » или «;»; необязательное в скобках — `(по)играть в мяч`; «играть» = «поиграть»; прощаются опечатки и другой порядок слов; кнопка «Мой ответ верный».
- **ИИ (Google Gemini, бесплатный ключ):** придумывает упражнения под набор и проверяет ответы по смыслу.
- **Импорт из Quizlet:** «⋯ → Экспортировать» на quizlet.com, скопировать текст и вставить в приложение.
- Работает офлайн, все данные хранятся на устройстве; есть резервная копия в файл.

## Запуск
Это статический сайт без сборки: открой `index.html` через любой веб-сервер или включи GitHub Pages
(Settings → Pages → Deploy from a branch → `main` / `root`).
