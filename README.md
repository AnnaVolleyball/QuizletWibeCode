# Карточки

Приложение для изучения английских слов по карточкам — как Quizlet, только с умной проверкой ответов и ИИ-заданиями. Сделано под iPhone (Safari → «На экран „Домой“»).

## Возможности
- **Режимы:** карточки, письмо, тест, подбор пар, ИИ-задания.
- **Умная проверка:** регистр, пунктуация и «ё/е» не важны; варианты через « / » или «;»; необязательное в скобках — `(по)играть в мяч`; «играть» = «поиграть»; прощаются опечатки и другой порядок слов; don't = do not; colour = color; sb/sth и кого-л. можно не писать; кнопка «Мой ответ верный».
- **ИИ (Google Gemini, бесплатный ключ):** придумывает упражнения под набор и проверяет ответы по смыслу.
- **Импорт из Quizlet:** «⋯ → Экспортировать» на quizlet.com, скопировать текст и вставить в приложение.
- Работает офлайн, данные хранятся на устройстве; есть резервная копия в файл.
- **Синхронизация (по желанию):** зашифрованная копия наборов на своём сервере, общие наборы на всех устройствах с одним ключом. Настройки → «Синхронизация». Как устроено — `docs/SYNC.md`, сервер — `server/README.md`.

## Запуск
Это статический сайт без сборки: открой `index.html` через любой веб-сервер или включи GitHub Pages
(Settings → Pages → Deploy from a branch → `main` / `root`).

## Файлы
- `index.html`, `style.css`, `app.js` (интерфейс, ИИ, синхронизация), `check.js` (умная проверка ответов).
- `sw.js` — офлайн-режим; при изменении файлов увеличивай версию `CACHE`.
- `server/` — сервер синхронизации (Python 3 без зависимостей) и файлы для установки.
- `docs/SYNC.md` — как устроена синхронизация и её статус.
